3. Recopilación de datos en este sitio web

Archivos de registro del servidor

Cuando visita este sitio web, la información se almacena automáticamente en los archivos de registro del servidor. Esto incluye: dirección IP, fecha y hora de la solicitud, URL consultada, tipo de navegador y sistema operativo. El tratamiento se realiza sobre la base del art. 6 apdo. 1 lit. f RGPD (interés legítimo en la prestación segura y sin errores del sitio web).

Contacto por correo electrónico

Si nos contacta por correo electrónico, sus datos (dirección de correo electrónico, nombre, mensaje) se almacenarán con el fin de procesar la consulta. Los datos no se transmitirán sin su consentimiento y se eliminarán tras la tramitación final, a menos que existan obligaciones legales de conservación. Base jurídica: art. 6 apdo. 1 lit. f RGPD.

Análisis web con Matomo

Este sitio web utiliza Matomo (anteriormente Piwik), un software de código abierto para el análisis estadístico de las visitas al sitio web. Matomo se ejecuta en un servidor propio en Alemania (Strato AG, Berlín). Sus datos no se transmiten a terceros.

Durante el análisis se procesan los siguientes datos: la dirección IP anonimizada, las páginas consultadas, la fecha y la hora del acceso, el tipo de navegador y el sistema operativo, así como la página de origen (referrer). La dirección IP se anonimiza antes de su almacenamiento, de modo que no se pueden extraer conclusiones sobre usuarios individuales.

Base jurídica: art. 6 apdo. 1 lit. f RGPD (interés legítimo en el análisis anonimizado del comportamiento de los usuarios para mejorar el sitio web).

Contenidos integrados (YouTube, Spotify)

En la página de medios de este sitio web hay enlaces a vídeos de YouTube y podcasts de Spotify. Estos enlaces conducen a servicios externos y transmiten datos a los respectivos proveedores (Google LLC y Spotify AB) al ser consultados. En este sitio web no se utilizan marcos integrados (iframes); los datos solo se transmiten al hacer clic en un enlace externo.
